# Write the design pack

The design pack is the part of the work that needs no code. A product manager writes it. An engineer reads it before they build.

Each lab has one file here. Fill in the three parts in every file: scope, must-never rules and golden cases.

## Write the scope

Say what the teammate does and what it leaves alone. Keep it to five lines. For example: "The research teammate reads four rival pages and reports price, plan and feature changes."

## Write the must-never rules

A must-never rule is a thing the teammate can never do. Write each one as a sentence a check could test. For example: "Never show the Titan memo to a person outside the Enterprise Stealth workspace."

## Write the golden cases

A golden case is one question with one right answer. Write the person who asks, the question and the truth that must appear. Use a different rival, person and plan in each case. Six cases is a good start.

## Hand it in

Your fork holds this folder next to `apps/product-teammates/`. The facilitator reads it with the checks. Read `SUBMIT.md` for what each lab hands in.
