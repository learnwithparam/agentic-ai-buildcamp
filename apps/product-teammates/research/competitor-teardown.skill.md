# Tear down a rival

Use this skill when the product lead wants the full picture of one rival.

## Read the pages

1. Capture the pricing page and the changelog page with Stagehand.
2. Keep each page as a snapshot. A page that did not change is skipped.
3. Compare each plan price with the last snapshot.

## Read the strategy brief

1. Read the strategy PDF with xberg.
2. Use only the words in the PDF. Do not guess a plan.

## Write the answer

1. Say what moved first. For example, say that Team went from 49 USD to 79 USD.
2. Cite the snapshot or the brief for every fact, in square brackets.
3. Use only numbers that appear in the cited text.
4. If nothing moved, say the page did not change.

## Never do this

- Never answer a question that is not about a rival. Send it to the template reply.
- Never state a price without a citation.
